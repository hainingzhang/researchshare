# Mac 成员使用指南

按此指南设置你的 Mac，通过 Finder 访问团队共享盘。服务器管理员应先创建你的个人 Linux 账号，并准备好服务器地址、SSH 端口及共享路径。

## 一次性配置

### 1. 获取仓库

下载或克隆本方案仓库到 Mac。本机需要安装 Homebrew；配置脚本会在需要时通过 Homebrew 安装 rclone。

### 2. 运行配置脚本

打开“终端”，进入仓库目录，运行：

```sh
bash macos/setup.sh
```

根据提示输入：

- 服务器地址（IP 或域名）
- 你的个人 Linux 用户名
- SSH 端口（默认 `22`）
- 共享目录路径（默认 `/home/ubuntu/data/research`）

脚本会生成本机 SSH 密钥、公钥复制到剪贴板，并在终端显示公钥。把以 `ssh-ed25519` 开头的**公钥整行**通过团队认可的渠道交给管理员。不要发送没有 `.pub` 后缀的私钥文件。

管理员确认已添加公钥后，回到终端按 Enter。首次 SSH 连接时，先和管理员核对终端显示的服务器指纹，再确认连接。脚本随后创建 rclone SFTP 配置并测试共享目录。

## 日常挂载与 Finder 使用

在仓库目录运行：

```sh
bash macos/mount.sh
```

保持终端窗口打开。打开 Finder，按 **Command+Shift+G**，输入 `~/ResearchCloud` 并回车，即可浏览共享文件。

使用结束并确认上传完成后，回到挂载终端按 **Ctrl+C** 卸载共享盘。

## 重要说明

- rclone 挂载是远程访问，不是下载到本机的离线同步。断网时远端文件可能无法访问。
- 上传和保存后请等待操作完成再卸载或关机。
- 其他成员刚上传的文件可能因目录缓存而稍后才显示（当前脚本使用 30 秒目录缓存）。
- 避免多人同时编辑同一份 Office 文件，以免互相覆盖。
- Git 研究项目保存在本地磁盘，不要放入 `~/ResearchCloud`。

遇到主机密钥错误时，停止操作并联系管理员核对指纹；不要关闭主机密钥检查。

服务器管理员步骤见 [服务器指南](../server/README.md)，Windows 成员步骤见 [Windows 指南](../windows/README.md)，综合流程见 [部署总指南](../DEPLOYMENT.md)。
